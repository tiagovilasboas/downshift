## How the project can sustain itself

Open source adoption is the distribution layer. Revenue typically comes from
services and products **around** the code, not from restricting the source:

| Model | Examples |
|-------|----------|
| **Hosted** | A possible managed offering (dashboards, org policies). Not built, not announced |
| **Support** | Paid integration help for enterprises |
| **Enterprise** | SSO, audit retention, SLA, private benchmarks |
| **Trademark** | "Downshift" as a brand for official binaries and cloud |

Forks and self-hosting are allowed under Apache 2.0. The maintainer competes on
velocity, official releases, harness compatibility matrix, and hosted convenience.
