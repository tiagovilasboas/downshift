# Release Notes & Migration Guide (W7.6)

Downshift by Tiago Vilas Boas · https://github.com/tiagovilasboas/downshift

## Release Highlights (v0.2.1 / Release Candidate)

### 1. Default Subagent Profiles Table (W7.1)
Zero configuration is required for immediate token savings in Claude Code. Built-in subagents are automatically routed:
- `Explore` ➔ `small` (Claude Haiku 5.5)
- `claude-code-guide` ➔ `small` (Claude Haiku 5.5)
- `statusline-setup` ➔ `small` (Claude Haiku 5.5)
- `general-purpose` and `Plan` ➔ Preserved at parent session model.
- If a security risk signal is detected in the prompt, tiers automatically elevate to `mid` (Sonnet).

### 2. Economy Mode (W7.9)
Enable aggressive token reduction across all subagents:
```bash
downshift policy economy on
```
Shifts all profiles down one relative tier within verified guardrails.

### 3. Policy Initialization (W7.2)
Initialize and customize project-level routing rules with dry-run verification:
```bash
downshift policy init
```

### 4. Claude Code Subagent Model Force Integration
`downshift setup` now automatically sets `"CLAUDE_CODE_SUBAGENT_MODEL_FORCE": "1"` in `~/.claude/settings.json`, ensuring Claude Code respects subagent model overrides without requiring custom shell wrappers.

### 5. Autonomous Engineering Loop Engine
Run autonomous BDI cycles with integrated verification and cascade auto-upgrades:
```bash
downshift loop --task="Task description" --sensor="go test ./..."
```

## Breaking Changes & Migration

1. **V1 Routing Deprecation:**
   - The legacy `downshift try` command and legacy routing v1 engine have been completely removed in favor of Decider v2.
   - Any custom scripts invoking `downshift try` should be updated to inspect decisions via `downshift session` or `downshift stats`.
2. **Environment Variable Changes:**
   - Legacy Naive Bayes experimental variables (`DOWNSHIFT_NB_*`) are deprecated and ignored.
   - State directory configuration is standardized on `~/.downshift` (legacy `~/.harness-downshift` is automatically migrated if present).

## Rollback Procedure
If rollback is required, revert the branch or binary to the previous release tag:
```bash
git checkout main
make install
```
Or execute complete clean removal:
```bash
downshift uninstall --purge
```
