# Release v0.6.0

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

This is a minor release with one breaking change: routing is now reported as tokens per harness, under one definition. The only figure named "tokens saved" is the Compactor's. Tokens that ran on a cheaper model are shown as workload, never as savings, and are never summed across harnesses. No figure is in money.

## What changed

### Breaking

- **Routing is reported as `routing_tokens`, per harness.** Each harness reports its billable tokens (input, output and cache write) that ran below the session model. The requested model is reported as a separate, labelled fallback, and cache read has its own field. `tokens_rerouted`, `tokens_saved` and `effect` are removed from `stats --export` (schema `4`), `report --json`, `session --panel` and the operator export (schema `3`). [CHANGELOG](../../CHANGELOG.md#060---2026-11-03) lists every changed key.

### Report

- **`downshift report --markdown`.** It prints the report as headings and tables, so it renders in a harness chat. The figures and wording are the same as in the text report.
- **"routed to a cheaper tier".** The routing line now has this wording and shows its share, for example `2.6M of 2.9M billable (89%; 19 of 21 spawns)`.
- **Main session reads and searches.** The report counts the main session's read and search calls: Claude Code's PostToolUse now also matches `Read|Grep|Glob`.

### Agents pane (Claude Code)

- **Scoped to this session.** The pane no longer lists other harnesses and no longer sums every session.
- **Tiles.** The tiles read AGENTS, TOKENS SAVED ("by the Compactor") and ON A CHEAPER MODEL (the share of claude-code tokens).
- **Routing section.**
  - The title reads "N of M agents on a cheaper model".
  - There is one row per harness, and no "unobserved" rows.
  - The note reads "Same tokens, cheaper model. Routing doesn't save tokens."
- **Layout.** Section titles have more room, and the NOW row has no frame.

### Compactor

- **`git push`, `git pull` and `git fetch` output is compacted.** The run is compacted whether it succeeds or fails. Ref updates, errors and failing tests are kept verbatim.
- **`npm test` and `pnpm test` runs lose the script banner.** Every failure stays.
- **Codex and OpenCode runs are attributed to their harness.** Before, they were counted as `unknown`.

### Squad

- **`downshift full-power`.** This is the trigger that activates every agent (alias `potencia-total`).
- **Fan-out scales with the work.** It grows with the number of independent ready parts, up to `orchestration.max_parallel` (default 6, was a fixed 4).

## What you need to do

1. Install v0.6.0.
2. Run `downshift setup claude-code --yes`. It updates the hooks, the plugin and the mod.
3. Open a new harness session.
4. If a script reads `tokens_saved`, `tokens_rerouted` or `effect`, switch it to `routing_tokens`.

## Roll back

Install v0.5.3 from the [releases page](https://github.com/tiagovilasboas/downshift-ai/releases).
