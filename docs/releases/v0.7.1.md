# Release v0.7.1

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

This is a patch release. It fixes what a code review of v0.7.0 found: published figures and rules that did not match the code, and backups that piled up on every setup. There is no breaking change and no new default. [CHANGELOG](../../CHANGELOG.md#071---2026-11-05) lists every change.

## What changed

- **CCR keeps ordinary lines.** Redaction withheld any line that mentioned `token`, `secret`, `cookie` or `authorization`, such as a `--- PASS: TestTokenBudget` line or a path to `secret.go`. Those words now count only as the name of an assignment or header. Key prefixes, URLs with credentials, JWTs and PEM blocks are still withheld.
- **Honest bench.** [bench.md](../reference/bench.md) now counts the marker line the compactor appends. The default total is 47.2% and 76.2% with CCR, down from 50.7% and 83.2%.
- **One backup per file.** `downshift setup` used to leave one `.downshift-bak-*` copy per run next to every file it wrote. The `downshift-agents` mod folder held 171 of them, inside a folder Claude Code watches. Setup now keeps only the newest, which is the one undo restores.
- **Docs.** AGENTS.md and the architecture doc no longer claim a 1.5 s hook deadline or that `internal/archtest` checks the behavioural invariants.

## What you need to do

1. Install v0.7.1.
2. Run `downshift setup --yes`. The next write of each file removes its older backups.
3. Open a new harness session.
