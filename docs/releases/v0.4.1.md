# Release v0.4.1

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift). A patch release on top of v0.4.0. It fixes `send` on a finished worker and builds the release binaries from a clean tree. Nothing was removed and no option changed.

## What changed

- **`send` resumes a finished worker.** In v0.4.0 the MCP server refused every `send` with "that worker cannot take another turn", even for a worker that ended `done` with its session id captured. The server builds its queue through `Routes(read, write)`, and that wrapper did not forward the resume call to the read or write launcher, so the resume check always failed. It now forwards it. In a live run over stdio, a Claude read worker answered a follow-up on the same session and remembered its first turn (#696).
- **Release binaries come from a clean tree.** `go.mod` listed `github.com/mattn/go-isatty` as indirect although `cmd/downshift` imports it, so goreleaser's `go mod tidy` hook rewrote `go.mod` during the build. The v0.4.0 binaries carry `vcs.modified=true`, and `downshift doctor` reports "built from a dirty tree" for them. `go.mod` is tidy now, and the release job fails before goreleaser runs if those hooks change any tracked file (#695).
- **Evidence.** The real Claude Code session that proved the eleven MCP tools, the compactor and routing on v0.4.0 is written up in `docs/evidence/claude-code-v0.4.0-real-session-2026-11-01.md`, with the `send` finding and its fix (#694, #696).

## What you need to do

- Install v0.4.1 and run `downshift doctor`. The build provenance line should no longer warn about a dirty tree, and the Claude Code MCP line should list eleven tools.

## Known limits

Unchanged from v0.4.0:

- A Codex worker gets its session id only after its first turn ends, so a cancel during that turn can leave its rollout file under `~/.codex/sessions`.
- `steer` uses the same stop-and-resume path for Claude and Codex; Codex's native mid-turn steer is not used yet.

## Roll back

Install v0.4.0 from the [releases page](https://github.com/tiagovilasboas/downshift/releases). Rolling back brings back the `send` refusal on finished workers.
