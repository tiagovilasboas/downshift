# Release v0.15.0

> **Product maturity: beta.** `v0.15.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. This release adds one command that updates Downshift for you, and redraws the README and docs images. [CHANGELOG](../../CHANGELOG.md#0150---2026-11-11) lists every change.

## What changed

- **`downshift update` installs the latest release and refreshes every harness in one command**, on macOS, Linux and Windows. It reads the tag from the releases page, downloads the archive for your platform, checks its sha256 against `checksums.txt` (and the build provenance when `gh` is installed), and replaces the binary in place. A failed check leaves the old binary untouched. Then the new binary runs `setup` (it shows the diff, then asks; `--yes` skips the question) and `doctor`. A current binary skips the download and still runs setup. `--check` only reports, and `--version vX.Y.Z` installs a named release.
- **The README and docs images have a new look.** The diagrams (21 SVGs and their PNG copies) and the four README raster artworks are drawn in a symmetric pencil-sketch style. Colours, text and logos are unchanged. The scripts are in `docs/brand/sketch/`.

## What you need to do

1. If you run v0.14.0, install v0.15.0 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases). `downshift update` does not exist in v0.14.0.
2. From v0.15.0 on, run `downshift update`. It installs the latest release, runs setup and runs doctor in one step.
