# Release v0.5.1

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift). A patch release on top of v0.5.0. It publishes the binaries v0.5.0 did not, and draws the band logo smaller. Nothing was removed and no option changed.

## What changed

- **Release tags publish again.** The `v0.5.0` tag passed every test but published no release: on a tag build the `e2e` job was skipped, and the jobs after it (`build-cross-platform`, `release`) were skipped with it. `e2e` now runs on `v*` tags, so the tag path builds and publishes (#777). Everything in [v0.5.0](v0.5.0.md) ships with this release.
- **Smaller band logo.** The `downshift-agents` band draws its bare, theme-aware logo at 20 px instead of 24 (#776).

## What you need to do

- Install v0.5.1, run `downshift setup claude-code --yes` to refresh the mod, and open a new Claude Code session to see the band.

## Roll back

Install v0.4.3 from the [releases page](https://github.com/tiagovilasboas/downshift/releases): v0.5.0 has no published binaries.
