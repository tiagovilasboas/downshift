# Release v0.4.2

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift). A patch release on top of v0.4.1. When the MCP server exits, it now deletes the session transcripts its finished workers left behind. Nothing was removed and no option changed.

## What changed

- **Server exit cleans up finished workers.** In v0.4.0 and v0.4.1 the server only stopped workers that were still running when it exited. A worker that had finished and was never passed to `release` kept its Claude transcript under `~/.claude/projects`; this was seen live on v0.4.1 when a client closed the server without calling `release`. The server now releases every finished worker on exit, as the v0.4.0 note already described (#698).
- **No crash on a late process exit.** A worker released after its cancel but before its process exited made the server panic when that exit landed. The server now ignores the late exit (#698).

## What you need to do

- Install v0.4.2 and run `downshift doctor`. The Claude Code MCP line should list eleven tools.

## Known limits

Unchanged from v0.4.1:

- A Codex worker gets its session id only after its first turn ends, so a cancel during that turn can leave its rollout file under `~/.codex/sessions`.
- `steer` uses the same stop-and-resume path for Claude and Codex; Codex's native mid-turn steer is not used yet.

## Roll back

Install v0.4.1 from the [releases page](https://github.com/tiagovilasboas/downshift/releases). Rolling back brings back the leftover transcripts when the server exits without `release`.
