# Release v0.7.0

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

This is a minor release. The Compactor covers many more command families and can keep what it cuts, the agent triggers now reach every harness's always-loaded instructions, and bare `downshift` opens a console. There is no breaking change to a JSON schema. Two defaults change: `downshift report` prints markdown (`--text` gives the old columns) and `downshift setup` opens its wizard in a terminal. [CHANGELOG](../../CHANGELOG.md#070---2026-11-04) lists every change.

## What changed

### Compactor

- **CCR, opt-in.** With `DOWNSHIFT_CCR=1` (or `"ccr": true`), the raw output is kept under `~/.downshift/ccr/` and `downshift retrieve <id>` (or the MCP tool `retrieve`) reads any part back, so repeated lines can fold. Bench saving goes from 47.2% to 76.2%. Bytes later retrieved are not yet subtracted from savings. See [CCR](../guides/ccr.md).
- **Failed runs.** jest, pytest and cargo test failures lose only the passing lines, like go test, vitest and playwright. Every failure line stays.
- **Git.** `git log` is one line per commit, lockfile diffs become package changes, and a danger word in unchanged diff context no longer keeps a diff raw.
- **More families.** Package installs and `npm audit`, `ls`, `find`, `grep`, `rg` and `git grep`, Bazel, Nx, Turborepo, Deno and Zig, markdown bodies of `gh issue view`, and stack families for CSS/HTML, JS/TS scripts, Python, Django and React Native.
- **Generic chain.** Successful runs with no known shape lose base64 blobs, collapse repeated lines, fold long stack traces and trim very long output. Paths under the working directory become relative.
- **Benchmark.** `make bench` writes [bench.md](../reference/bench.md).

### Agents

- **Triggers in every harness.** `downshift setup` writes `downshift full power` and `downshift shift <squad>` into the instructions each harness always loads: `~/.claude/CLAUDE.md`, Codex, Antigravity, OpenCode and KiroCrew. Before, the trigger lived only in a skill, so a session could miss it and work alone. Cursor has no global file; see the [install guide](../guides/install.md#agent-triggers-every-harness-with-an-instructions-file).
- **`downshift plan`.** It checks the lead's delegation plan and prints it as a table.
- **Security skill.** The `security` agent uses Cloudflare's optional `security-audit` skill in guidance mode when installed.

### Console and report

- **Console.** Bare `downshift` in a terminal opens a full-screen console. Read-only commands open on their output; `--plain` or `DOWNSHIFT_PLAIN` keeps plain text.
- **Report.** `downshift report` prints markdown by default, breaks the Compactor down by command family and adds an Efficiency section per harness.

### Agents pane (Claude Code)

- New sprites, eased progress bars, stale agents shown apart, an Efficiency card, a "Top families" Compactor block and `/ds-agents report`.
- The task list is cleared when the turn wraps up.

## What you need to do

1. Install v0.7.0.
2. Run `downshift setup --yes` (or `downshift setup` for the wizard). It updates the hooks, the plugin, the mod and the agent triggers.
3. Open a new harness session.
4. If a script parses `downshift report` text, pass `--text`.

## Roll back

Install v0.6.0 from the [releases page](https://github.com/tiagovilasboas/downshift/releases) and run `downshift setup --undo` to restore the previous instructions files.
