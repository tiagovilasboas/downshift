# Release v0.8.0

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

This is a minor release. Read-only workers are on by default for Claude, OpenCode gets a bridge plugin, the Compactor saving is guarded by tests, and the docs now say which features are still in development. [CHANGELOG](../../CHANGELOG.md#080---2026-11-05) lists every change.

## What changed

- **Read-only workers on by default for Claude.** One setting, `orchestration.workers` (`off`, `read`, `write`), decides whether `delegate` runs. Claude on macOS and Linux defaults to `read`. Codex and Windows stay `off` until they have evidence. Write mode is never the default. `downshift setup --workers` and `downshift doctor` show and change it.
- **OpenCode (Beta).** `downshift setup opencode` installs a bridge plugin and the MCP server. Routing, the honored model and shell compaction were observed live on OpenCode 2.2.5. The retry fallback is not verified yet.
- **Planner as an MCP tool.** The `plan` tool fills a plan with tiers, waves and next steps and stores nothing. The planner is still in development.
- **Compactor saving guard.** A per-family baseline fails the build when a family's saving drops. Lossless families must keep every failure line, and a failing fixture must stay byte-identical.
- **Docs that match the code.** Tests check cited tests, defaults, environment variables, MCP tools, CLI flags and the harness matrix against the code. Each release attaches `docs-manifest.json`.
- **Honest maturity.** The README and each feature page mark the status: stable, beta, in development or experimental.
- **OmniRoute removed.** 9router is the only gateway.

## Still in development

Planner, the setup wizard, Compressor Learning, Token Accounting, and workers on Codex and Windows. Antigravity and KiroCrew are experimental. [Maturity](../../README.md#maturity) has the full table.

## What you need to do

1. Install v0.8.0.
2. Run `downshift setup --yes`. On OpenCode, run `downshift setup opencode`.
3. If you used OmniRoute, run `downshift gateway on 9router` or leave the gateway off.
4. Open a new harness session.
