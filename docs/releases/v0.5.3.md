# Release v0.5.3

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai). A patch release on top of v0.5.2. Setup now updates an installed Claude Code plugin, so the Downshift agent squad reaches existing installs, and the `downshift-agents` band and pane get a visual polish. Nothing was removed and no option changed.

## What changed

- **Setup updates the installed plugin.** Claude Code keeps a plugin on the commit it first fetched. `downshift setup` now runs `claude plugin marketplace update` and `claude plugin update` when the plugin is already enabled, so a new release's agents and skills reach the session. Before, an older install kept only `mechanical-worker` and `downshift full force` could not find the squad (#789).
- **Logo closer to its title.** In the band and the pane the logo sits closer to "Downshift Agents", with 4 px of room on its left (#787).
- **Claude's orange instead of yellow.** Warnings and the Compactor figures use Claude's orange, in the terminal and on desktop (#787).
- **Dimmed pane borders.** The pane's borders are drawn dimmed, so the sections read lighter (#787).

## What you need to do

- Install v0.5.3, run `downshift setup claude-code --yes` (it now updates the plugin and the mod), and open a new Claude Code session.

## Roll back

Install v0.5.2 from the [releases page](https://github.com/tiagovilasboas/downshift-ai/releases).
