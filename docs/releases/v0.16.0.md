# Release v0.16.0

> **Product maturity: beta.** `v0.16.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. This release makes compacted output smaller, and makes `doctor` check that the post-run replacement reached the model. [CHANGELOG](../../CHANGELOG.md#0160---2026-11-11) lists every change.

## What changed

- **Passing test runs are shorter once the raw output is kept** (CCR on, the default). `go test` drops its per-package rows and keeps the counts and the coverage range; Pytest, Cargo test, Playwright, Vitest, dart/flutter test, RSpec, dotnet test, Cypress and `go test -v` drop the duration from their count line. Everything cut comes back with `downshift retrieve <id>`. Bench with CCR on: 68.3% to 69.4%.
- **Test runs inside a `make` or script log fold.** A complete passing `go test -v`, pytest or vitest block inside another program's output becomes that runner's own summary; every other line stays as printed. A 48-line `make test` log goes from 1,690 to 476 bytes.
- **A shorter marker that says whether the cut is final:** `[downshift compact: N to M bytes; downshift retrieve <id>]`, or `original not kept` when no copy was stored.
- **Retrieve is charged to the right session.** The hint names the session (`downshift retrieve --session=<12 hex> <id>`), so a read no longer counts against another session that kept the same output.
- **`downshift doctor` checks post-run honor.** A `post-run replacement` row per harness counts how many compacted post-run outputs the harness actually used, read offline from its transcripts.
- **Post-run rows name the program inside a compound command** (`inner`, `kind`), fixed codes only, to measure where widening the wrapper would pay.
- **Fixes:** the notes `compact` appends (`2>/dev/null`, `|| true`) now count in the "never longer than raw" check, and several docs quoted stale figures. The bench report now fails CI when it goes stale.

## What you need to do

1. Run `downshift update` (from v0.15.0), or install v0.16.0 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. Open a new harness session so the hooks load the new binary.
