# Release v0.17.1

> **Product maturity: beta.** `v0.17.1` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

A patch release that fixes the search cut shipped in v0.17.0. [CHANGELOG](../../CHANGELOG.md#0171---2026-11-12) lists every change.

## What changed

- **The search cut no longer cuts text that is not search rows.** In v0.17.0 a command led by `grep`, `rg` or `git grep` was cut whatever followed the search: `grep -n x f && sed -n 1,60p f` lost the file text the agent asked for, and a `grep -l` file list, a `uniq -c` count or Windows paths were cut to 25 lines. The cut now runs only when nine lines in ten are search rows, never past an explicit `head -n N` or `tail -n N` the output fits, and it looks past a leading `cd dir &&`.
- **The v0.17.0 figure was wrong.** Re-measured over the same 14 days of real transcripts, the corrected cut takes 13 outputs and saves 22 KB, not 183 outputs and 210 KB: most of those were the wrong cuts above.
- **`rg` output under 16 KB is cut in `downshift compact` too**, on every harness, with the raw output kept for `downshift retrieve`. A cut row now ends with ` …`.

## What you need to do

1. Run `downshift update`, or install v0.17.1 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. Open a new harness session so the hooks load the new binary.
