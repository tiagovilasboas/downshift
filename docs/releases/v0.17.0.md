# Release v0.17.0

> **Product maturity: beta.** `v0.17.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. This release cuts search output that used to reach the model whole, records kiro-cli 3.x subagent spawns, and ships a standard library security fix. [CHANGELOG](../../CHANGELOG.md#0170---2026-11-11) lists every change.

## What changed

- **Search output led by `grep`, `rg` or `git grep` is cut at any size once its raw output is kept.** A piped or chained search (`grep -rn x . | head`, `git grep -n x | grep -v y`) used to reach the model whole under 16 KB. The post-run hook now keeps the first 25 rows of each file and 200 in all, cuts kept rows at 80 bytes once a row is dropped, and counts the rest per file. `downshift retrieve <id>` returns everything. Over 14 days of real transcripts, this cut 183 of 1,312 search outputs and saved 210 KB (10% of their bytes). No later tool call needed a dropped row.
- **kiro-cli 3.x subagent spawns are recorded.** Its model-less `subagent` tool is now observed like a Kiro IDE spawn and is never blocked.
- **Security:** binaries are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`.

## What you need to do

1. Run `downshift update` (from v0.16.0), or install v0.17.0 with `install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases).
2. If you use KiroCrew, run `downshift setup` again to add the `subagent` matcher.
3. Open a new harness session so the hooks load the new binary.
