# Release v0.10.0 (public beta)

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#0100---2026-11-07) lists every change.

## What changed

- **CCR on by default.** `downshift compact` now keeps the raw output of every compacted command under `~/.downshift/ccr/` (0600, 24 h, 8 MiB per entry, 64 MiB total, secret-looking lines withheld), allowing full outputs to be read back on demand with `downshift retrieve <id>`. Output bytes retrieved via `retrieve` are accurately subtracted from net token savings in `report`, `session`, `stats` and the panel.
- **Dirty `git status` compaction.** `git status` output with staged, unstaged or untracked changes is now compacted cleanly (~45%–76% token reduction) by stripping git advice lines (`(use "git ...")`), upstream "up to date" notices, blank lines and boilerplate footers, while keeping branch headers, tracking lines, section headers and modified file paths 100% verbatim. Conflicts, detached HEAD, rebase/merge states and diverged branches continue to fail-open raw.
- **Local tool binaries allowlist.** `./node_modules/.bin/<tool>` and `./.venv/bin/<tool>` (and relative/unprefixed variants) are now accepted across all allowlisted JS/TS and Python tools (`vitest`, `jest`, `tsc`, `playwright`, `cypress`, `next`, `vite`, `turbo`, `eslint`, `prettier`, `biome`, `pytest`, `ruff`, `mypy`, etc.), matching existing `./vendor/bin/` PHP support. Watch, preview and mutating forms remain refused.
- **Quiet test suites and size safety.** `pytest -q` quiet transcripts are now recognised and compacted, and CCR markers are prevented from ever exceeding or equalling the original command output size.
- **Hook overlap detection in doctor.** `downshift doctor` now diagnoses and warns about conflicting `PreToolUse` hooks (such as RTK or cheap-subagents) rewriting the same tool fields in the same hook file.

## What you need to do

1. Install v0.10.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift/releases)).
2. Run `downshift doctor` and follow any recommendations.
3. Open a new harness session and check `downshift session`.
