# Release v0.9.0 (public beta)

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

This is the first public beta. Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#090---2026-11-06) lists every change.

The repository starts a fresh history with this release. Earlier tags and releases are not carried over; install v0.9.0 or later.

## What changed

- **The compactor reads more of what agents run.** File reads (`cat`, `head`, `tail -n`, `sed -n 'A,Bp'`, `wc -l`) fold long files to an outline with exact line ranges. `rg` and `grep -r` group matches per file with caps. JSON documents show their schema, repeated log lines collapse with a count, and `curl`/`wget -O -` keep the status, key headers and the ends of the body, with credentials redacted.
- **More families.** `rspec`, `dotnet test`, `phpstan`, `rubocop`, `docker build|ps|images`, `kubectl get`, `git stash list` and the read-only `glab` commands. Large `go test -v`/`-json`, jest and vitest runs fold passing tests and keep every failure.
- **Quoted and compound commands.** Quoted words, a trailing `2>/dev/null` or `|| true`, `cd dir && cmd`, `cmd | tail -N` and `&&`/`;` chains are wrapped, and the compound shapes run only for a harness that declares a POSIX shell.
- **Failures stay retrievable.** When a compacted command fails, the raw output is kept and the marker gives the id for `downshift retrieve`.
- **Measurement.** `downshift discover` finds commands that ran bare but could have been compacted. `downshift report --daily` and `--history` show tokens kept out of the context and tokens that ran below the session model, per harness.
- **Safer by default.** Codex and Cursor shell rewrites are limited to read-only commands, worker diffs no longer run repository git programs, compressor learning stores no arguments, and releases are verified on three OSes and signed before they are published.
- **Setup and doctor.** Setup skips only a linked file instead of the whole harness, keeps backups under `~/.downshift/backups`, and handles a running Claude Desktop. `doctor` checks every MCP registration, version skew between the binary, plugin and bridge, and stale hook binaries on Windows.

## What you need to do

1. Install v0.9.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift/releases)).
2. Run `downshift setup --dry-run`, review the diff, then `downshift setup --yes`.
3. Run `downshift doctor` and follow each `fix`.
4. Open a new harness session and check `downshift session`.

If you cloned the repository before, point your remote at it again: `git remote set-url origin https://github.com/tiagovilasboas/downshift.git` and clone fresh, because the history is new.
