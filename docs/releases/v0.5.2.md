# Release v0.5.2

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift). A patch release on top of v0.5.1. It catches an older `downshift` that shadows the new one on PATH, and makes the `downshift-agents` pane shorter and easier to read. Nothing was removed and no option changed.

## What changed

- **Shadowed binary, caught at install.** When an older `downshift` comes earlier on PATH (often `~/go/bin`), `install.sh` now warns and prints the `ln -sf` that fixes it, so a fresh install is the one that runs (#780).
- **Shadowed binary, caught by doctor.** `downshift doctor` has a `binary shadowed` check: it warns when two different `downshift` copies are on PATH and says how to keep one (#782).
- **Agent instructions reinstall a stale binary.** `AGENTS.md`, `llms.txt` and the `downshift-setup` skill tell an agent to install when `downshift version` is older than the latest release, not only when it is missing, then check `which -a downshift` (#781). They also name what setup adds besides hooks (MCP server, skills, the mod), and `GEMINI.md` joins the instruction files (#779).
- **Compact `/ds-agents` pane.** On desktop the pane has a one-row header with the current theme-aware logo, task progress first, colored section titles and icons, and tighter spacing. The Compactor and Routing detail counts move behind Expand details (#784).
- **Smaller band logo.** The band draws its logo at 12 px instead of 20 (#783, #785).

## What you need to do

- Install v0.5.2, then check `which -a downshift`: the first copy must be the new one. `downshift doctor` now says so too.
- Run `downshift setup claude-code --yes` to refresh the mod, and open a new Claude Code session to see the band and the pane.

## Roll back

Install v0.5.1 from the [releases page](https://github.com/tiagovilasboas/downshift/releases).
