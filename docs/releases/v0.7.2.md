# Release v0.7.2

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

This is a patch release. It closes the remaining findings of the v0.7.0 code review and ships the new setup wizard and report screen. One behaviour changes on purpose: setup no longer writes through a symlinked file. [CHANGELOG](../../CHANGELOG.md#072---2026-11-05) lists every change.

## What changed

- **Setup leaves linked files alone.** When a file setup would write is a symlink (for example into a dotfiles repository), setup reports it and leaves it as it is, as the setup rule always said. Every other file is still written. Backups are written atomically.
- **Full power checks quota first.** "Downshift full power" now calls `providers`, reads the `strain` block, sizes the squad to the task and runs at most 5 agents at once. Exploration is delegated to a researcher instead of forbidden.
- **Lossy folds are labelled.** The compactor records `folded` beside `compacted`, so a lossy fold (raw kept in CCR) is no longer counted as the lossless compressor. The summary adds `folded_runs` and `folded_saved_bytes`; totals do not change. Savings are computed in one place.
- **Bench by class.** [bench.md](../reference/bench.md) labels each family lossless or lossy (69.4% and 38.0% saved) and measures cargo_test, tsc and eslint on 3 fixtures each. The default total is 48.9%, 76.1% with CCR.
- **Setup wizard and report screen.** In a terminal, `downshift setup` opens a full-screen wizard and `downshift report` a report screen with tabs. `--text`, `--json` and `--markdown` are unchanged.

## What you need to do

1. Install v0.7.2.
2. Run `downshift setup --yes`. If it reports a linked file, edit the real file by hand or remove the link.
3. Open a new harness session.
