# Release v0.11.2 (public beta)

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#0112---2026-11-07) lists every change.

## What changed

- **One binary, not two.** `install.sh` now updates the downshift already on your PATH (for example `~/go/bin` after `go install`) instead of installing a second copy in `/usr/local/bin` or `~/.local/bin`, where one copy shadowed the other and doctor warned `binary shadowed`. A linked copy is left alone, and `DOWNSHIFT_INSTALL_DIR` still wins.
- **The agents band counts what runs now.** The `downshift-agents` band reads `Agents N active` instead of `N/total`, whose total counted every subagent of the session. In the pane's active view, a stale agent whose end never arrived drops out after 10 minutes of silence, together with the idle orchestrator row; it stays in the full list.
- **Doctor names fewer overlaps.** The `hook overlap` check names only cheap-subagents for the subagent model; other hooks on the same tool are counted under `--verbose`.

## What you need to do

1. Update to v0.11.2 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases)).
2. Run `downshift setup --dry-run`, then `downshift setup --yes` to refresh the `downshift-agents` mod.
3. Run `downshift doctor`. If it still warns `binary shadowed`, remove the copy it names.
