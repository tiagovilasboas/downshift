# Release v0.11.0 (public beta)

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#0110---2026-11-07) lists every change.

## What changed

- **Major compactor enhancements and benchmark gains.** Across the full test corpus of 107 fixtures, Downshift achieves a **51.1% raw reduction** (from 130,570 raw bytes down to 63,861 bytes) and **72.0% token reduction** (down to 36,559 bytes) with Command Context Recovery (CCR) repeat folding enabled by default.
- **Lossless test failure folding (Go test & Pytest).** Test failure output is folded intelligently to preserve 100% of user-relevant debugging signals:
  - *Go test:* Folds stdlib runtime and testing panic frames, shortens headers, condenses multi-package passing suites without coverage to single summary lines, and preserves 100% of user stack frames and assertion failures (15/15 facts preserved on failure suites).
  - *Pytest:* Counts passing dots on mixed progress lines, strips non-error test body lines in failure blocks, deduplicates short summaries, and preserves 100% of user stack frames and failure reasons (12/12 facts preserved).
- **Dirty `git status` short formatting & `ls -la` long listing filter.**
  - *Dirty git status:* Strips git advice hints (`(use "git ...")`), upstream tracking boilerplate, blank lines, and footers, formatting dirty repositories into a compact short/porcelain view with branch tracking for a ~66% token cut.
  - *Listing commands (`ls -l`, `ls -la`):* Filters out extraneous column noise (permissions, owner, group) while preserving file sizes, timestamps, and paths for a ~58% token cut. Repeat folding thresholds are calibrated to prevent over-folding on small listings (<60–100 items).
- **Command Context Recovery (CCR) active out of the box.** Raw command output is stored safely under `~/.downshift/ccr/` (0600 permissions, 24 h retention, 8 MiB per entry cap, 64 MiB total cap, secret redaction heuristics), enabling complete command transcripts to be retrieved on demand with `downshift retrieve <id>`. Retrieved bytes are automatically subtracted from reported savings across `session`, `report`, and `stats`.
- **Natural language context triggers.** Conversational dispatch triggers (`downshift full-power`, `potência total`, `força total`, `downshift shift <squad>`) are officially supported, allowing immediate activation of specialized agent squads (`security`, `quality`, `core`, `leadership`) in multi-agent workflows.
- **Antigravity harness promoted to Functional.** Antigravity integration is now promoted from Experimental to Functional status, featuring complete `downshift setup` support, MCP server tools, and verified hook-based execution.
- **Setup wizard stabilized.** `downshift setup` is now Stable, providing automated, non-destructive configuration with symlink preservation, isolated timestamped backups under `~/.downshift/backups/`, and conflict diagnostics in `downshift doctor`.
- **Complete Portuguese (PT-BR) documentation hub.** A comprehensive documentation hub is now available under `docs/pt-br/`, providing Brazilian and Lusophone developers with translated quickstarts, reference guides, benchmark explanations, and architectural docs.

## What you need to do

1. Install or update to v0.11.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift/releases)).
2. Run `downshift doctor` and review your environment status.
3. Open a new harness session and verify metrics with `downshift session`.
