# Release v1.0.0

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift](https://github.com/tiagovilasboas/downshift).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#100---2026-11-08) lists every change.

## What changed

- **Hardened AWS STS and SSM secret redaction in CCR.** Command Context Recovery (`internal/ccr`) now sanitizes structured AWS STS session credentials (`AccessKeyId`, `SecretAccessKey`, `SessionToken`, `ASIA...` keys across JSON, CLI table, text, and environment variables) and AWS SSM Parameter Store outputs (`Value` inside `Parameter`/`Parameters` JSON blocks, CLI text, and table rows) in place to `[REDACTED]`, preserving valid JSON structure and non-secret `Value` fields.
- **Accurate model accounting on refuted rewrites.** When a harness refutes a model rewrite (for example, because another hook on the same call set a third model and won), `downshift stats` (`Models:`) and the statusline now attribute the run to the model reported by the `resolved` record rather than assuming the originally requested model ran. `downshift stats --detail` now reports `refuted` counts separately from `unobserved`.
- **No accidental user-wide policy from `downshift setup` in `HOME`.** Running `downshift setup` from the directory that holds the user state directory (usually `HOME`) now skips offering a project policy (`policy: skipped:`), preventing `.downshift/policy.json` in `HOME` from acting as a catch-all floor for every repository below it. `downshift policy init` still writes it when explicitly requested.
- **Honest harness maturity & doctor capability checks.** Cursor and Antigravity are consistently listed as Experimental across English and Portuguese documentation, `downshift doctor` reports declared harness capability limits as `ok` rather than `warn` (linking to [known limitations](../reference/known-limitations.md)), and new evidence reconciliations cover Anthropic documentation claims, effort/prompt-cache mechanics, and RouteLLM comparisons.
- **Toolchain-pinned `gofmt` and OpenCode test stability.** `make check`, `make check-changed`, and the lefthook pre-commit hook now invoke `gofmt` from `go env GOROOT` so local formatting matches CI, and OpenCode hook tests scale timeouts cleanly under parallel load.

## What you need to do

1. Update to v1.0.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift/releases)).
2. Run `downshift setup --dry-run`, then `downshift setup --yes` to refresh your installed hooks and plugin stamps.
3. Run `downshift doctor` to verify version sync across your binary, plugin, and PATH.
