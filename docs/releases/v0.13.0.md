# Release v0.13.0

> **Product maturity: beta.** `v0.13.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#0130---2026-11-09) lists every change.

## What changed

- **Desktop reads are compacted (`agent-desktop`).** `agent-desktop snapshot` and `agent-desktop find` read an app's accessibility tree as JSON, and an agent reads it again after every action. The Compactor now re-encodes each read one line per element with every field kept (a test decodes the view back to the same JSON), and sends a repeat read of the same window as only the lines that changed. It works in every harness: automatic in Claude Code, and through `downshift compact -- agent-desktop snapshot ...` elsewhere. The delta needs CCR to have kept the raw read (`downshift retrieve <id>` gives it back whole) and is scoped to the hook session, or to the working directory for a direct call. `DOWNSHIFT_DESKTOP_DELTA=0` turns the delta off. Guide: [agent-desktop](../guides/agent-desktop.md).
- **Counted like any family.** Each read is logged in the `agent-desktop` family and shows in `downshift report`, `downshift stats`, the session panel and the `downshift-agents` pane, with bytes read back through `retrieve` subtracted.
- **The benchmark uses the whole current corpus.** 110 compacted fixtures, with the agent-desktop reads counted: **67.1% fewer bytes with CCR on, 53.0% with it off, 60.3% on the 62 lossless fixtures** (before: 72.0%, 51.1% and 65.2% on 107 fixtures; the change is the added fixtures, no family got worse). `make bench` now computes the summary of `docs/reference/bench.md` from its rows.
- **Documentation.** README (English and Portuguese) and the evidence guide cite the current figures, and the README explains how Downshift protects the context window and where effort routing stands ([roadmap](../product/roadmap-context-and-reasoning.md)).

## What the numbers are

The desktop figures come from synthetic reads built to the tool's output schema and measured with the `downshift` binary, not from a live desktop: a first read had 53–60% fewer bytes, a repeat read after one action about 97% fewer, and a read, act, verify loop of three reads 84.9% fewer. A live-desktop measurement is still to be done; the guide says how to run it.

## What you need to do

1. Update to v0.13.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases)).
2. Run `downshift setup --dry-run`, then `downshift setup --yes` to refresh your installed hooks and plugin stamps.
3. Run `downshift doctor` to verify version sync across your binary, plugin, and PATH.
