# Release v0.14.0

> **Product maturity: beta.** `v0.14.0` is the latest release while Downshift works towards its
> [beta exit criteria](../reference/beta-exit.md). Cursor rewrite honor and independent
> multi-operator usage remain unverified. Consult the
> [known limitations](../reference/known-limitations.md) before adopting it.

Downshift by Tiago Vilas Boas: [github.com/tiagovilasboas/downshift-ai](https://github.com/tiagovilasboas/downshift-ai).

Downshift cuts the tokens an AI coding agent spends: it compacts verbose command output before it reaches the context, applies the orchestrator's model choice to each subagent within your policy, and measures both. Its own code never calls an LLM, and every hook fails open. [CHANGELOG](../../CHANGELOG.md#0140---2026-11-10) lists every change.

## What changed

- **Large outputs are cut to what the agent acts on (balanced compaction, on by default).** An output over 16 KB whose raw text CCR stored keeps a log's head, tail and failure lines, a diff's file and hunk headers, and a search's first matches per file; the marker names the `downshift retrieve` id for the rest. Measured on this repository: `go test -v` 591 KB → 33 KB, `git grep` 1.35 MB → 20 KB. `DOWNSHIFT_BALANCED=0` keeps outputs lossless.
- **Post-run compaction on Claude Code.** A shell command the pre-run rewrite could not wrap (a pipe, a redirect, a long command), and a Grep or Glob result over 16 KB, are compacted after the run through `updatedToolOutput`, with the raw text in CCR. `DOWNSHIFT_POST_COMPACT=0` turns it off. Design: [post-run compaction](../design/post-run-compaction.md).
- **More commands are wrapped before they run.** The command inside `cd <dir> && …`, `… 2>&1 | tail -N` or a `;`/`&&` chain may now hold quoted words, as in `go test -run 'A|B' ./... 2>&1 | tail -20`. Parts kept as written stay on the strict gate, and deny and ask rules apply to every part.
- **Faster start.** Package init dropped from about 14.7 ms to 1.3 ms; `downshift version` runs in about 5 ms and a Bash hook call in about 6 ms on one machine.
- **Honest figures.** The `downshift-agents` band shows `Compact 0/45` in a muted colour when a session cut nothing, instead of a warning-coloured `~0*`. `downshift doctor` says what the quota gate does with a stale reading instead of claiming it routes on it, and names the Codex feature flags the hooks need.
- **Support tiers.** The harness matrix and README rank each harness Supported, Beta or Experimental, with the evidence for each.

## What you need to do

1. Update to v0.14.0 (`install.sh` or the [release assets](https://github.com/tiagovilasboas/downshift-ai/releases)).
2. Run `downshift setup --dry-run`, then `downshift setup --yes` to refresh your installed hooks, plugin and steering.
3. Run `downshift doctor` to verify version sync across your binary, plugin, and PATH.
