# Downshift README media kit

Downshift by Tiago Vilas Boas · https://github.com/tiagovilasboas/downshift-ai

The assets in this directory support the English and Brazilian Portuguese project introductions. Diagrams are available as editable SVG and PNG exports. The official logo marks remain in the [brand directory](../).

| Asset | Purpose |
| --- | --- |
| `hero.png` | Cover illustration inspired by the Downshift Agents characters. |
| `operating-surfaces` | The separate model-routing and command-output touchpoints. |
| `setup-flow` | Interactive setup, review, confirmation and verification. |
| `compaction` | A synthetic before-and-after example and optional CCR recovery. |
| `command-families` | Recognized command families and pass-through limits. |
| `routing` | Per-spawn policy, session models and harness behavior. |
| `agents.png` | Concept illustration of independent agent work. |
| `agents-panel-illustration.png` | AI-edited illustration based on a Claude Code panel screenshot; task labels, model names and session metrics have been concealed. It is not an unaltered screenshot. |
| `compatibility` | Snapshot of harness status and routing evidence; check the current [matrix](../../reference/harness-matrix.md) before reuse. |
| `evidence` | Separate benchmark results and their scope; see [compaction benchmark](../../reference/bench.md) and [routing study](../../evidence/four-arm-mechanical-2026-10-21.md). |
| `social-cover.svg` / `.png` | Social cover using the official mark, with its background also provided separately. |

The artwork uses a dark surface with white, gray and green accents. The example output in `compaction` is synthetic and illustrates the flow, not an actual measurement. Original screenshots and corporate material are not included in this directory.

Routing behavior and available models vary by harness and session. The routing trial predates decision O8; its result does not measure the implementation after O8. Measured bytes, estimated tokens, actual token usage and billing are distinct quantities.
