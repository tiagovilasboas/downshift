# downshift-labs (private) — template

Create a **private** GitHub repository `tiagovilasboas/downshift-labs` (or local-only) for content that must not ship in the public OSS repo.

## Suggested contents

| Path | Purpose |
|------|---------|
| `BACKLOG.md` | DS/HC/KB execution contract, agent handoff rules |
| `NEXT-STEPS.md` | Weekly maintainer checklist, beta exit dogfood |
| `eval/` | Production-derived labels, exports (redacted), not in public benchmarks |
| `commercial/` | Cloud SKU drafts, pricing, enterprise pipeline |
| `research/` | Pre-publish gateway or router experiments |

## Do not copy here

- Corporate employer KB rules (`voomp-kb`) or personal vault dumps without redaction.
