# MCP capability spike (2026-10-28)

Downshift by Tiago Vilas Boas · https://github.com/tiagovilasboas/downshift

Two web readings of primary sources, to decide what the MCP server should offer next. Sources: the MCP
specification and changelog for 2025-11-25 and 2026-07-28 (modelcontextprotocol.io), and the Claude Code MCP,
hooks, permissions and plugins pages (code.claude.com/docs). Facts the readers could not confirm are marked.

## What Claude Code does with a server

| Mechanism | Finding | Use for Downshift |
|---|---|---|
| Server `instructions` | Put in context at session start, cut at 4096 characters. With tool search, only tool names and instructions load up front. | Done: rewritten to lead with the rule for when to call, 1500 characters at most. |
| Tool search | MCP tool definitions are deferred and found on demand. | Risk that `providers` is never found. |
| `_meta["anthropic/alwaysLoad"]` | Per tool, from Claude Code 2.1.287. The tool loads at session start. | Done on `providers`, the entry point. `claude mcp add` has no flag for it. |
| Tool annotations | `readOnlyHint` lets calls run in parallel; `idempotentHint` allows one retry. No documented effect on permission prompts (unconfirmed). | Done: title, read-only, idempotent, not destructive, closed world. `providers` is not read-only because it stores a hint. |
| Permission rule `mcp__downshift__*` | Removes the prompt for the server's tools. | A change to the user's permission settings, so setup does not write it. Offered as advice. |
| `SessionStart` hook `additionalContext` | The one way to push a short factual line into context. | Candidate, not built. |
| Output limits | Warning at 10k tokens, cap 25k. | No issue: results are small. |

## What the protocol allows beyond tools

| Feature | Verdict |
|---|---|
| `outputSchema` and `structuredContent` | Candidate: typed providers, status and apply for the orchestrator. Not built. |
| Resources and prompts | Maybe: the playbook and the provider list as read-only resources; surfaced by `@` and `/` in Claude Code. Not built. |
| Sampling, elicitation, roots | No. Sampling would make Downshift call an LLM; elicitation asks the user; roots is deprecated in 2026-07-28. |
| Tasks | No, until the worker tools exist (stage 4). |
| Logging | Deprecated in 2026-07-28; do not invest. |
| Deterministic `tools/list` order | Cheap, helps prompt caching; the SDK order is already stable. Unchecked. |

## Not confirmed

Whether Claude Code skips a permission prompt for `readOnlyHint`; whether subagents inherit the parent's MCP
tools; any measured rise in call rate from the new instructions. The last one is the proof that V3 still needs.
