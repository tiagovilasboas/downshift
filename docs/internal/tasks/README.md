# Internal task plans (public stub layer)

Downshift by Tiago Vilas Boas · https://github.com/tiagovilasboas/downshift

Dated folders under this path record **intent, decisions, and card names** for
maintainer work. They are Apache-licensed like the rest of the repo.

| Keep here | Move to private `downshift-labs` |
|-----------|----------------------------------|
| Roadmap status, D1–D6 style decisions | Full wave briefs with local paths |
| Product acceptance criteria | Raw eval batteries, redacted manifests |
| Links to merged PRs and public evidence | Commercial SKU drafts, squad playbooks |

Boundary reference: [docs/reference/publishing-boundaries.md](../../reference/publishing-boundaries.md).

When a plan references `~/.downshift` or `~/.downshift-eval`, the executable
detail belongs in `downshift-labs` under `docs/maintainer/` or `eval/labels/`.
